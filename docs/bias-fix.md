# 官途模拟器 - 偏差修复文档

## 问题概述

在原始版本中，玩家报告无论怎么选择，往往都会落入"落马"或"降职处分"的不良结局。经过测试分析，确认存在明显的计算偏差。

## 偏差原因分析

### 1. 风险计算过于严苛

原始代码中：
```javascript
const diffFactor = difficulty === 'easy' ? 0.7 : difficulty === 'hard' ? 1.4 : 1.0;
const risk = (100 - integrityScore) * diffFactor;
if (risk >= 70) {
    // 落马结局
}
```

**问题**：
- 在普通难度下，廉洁度 ≤30 就会落马
- 在困难难度下，廉洁度 ≤50 就会落马
- 这意味着大部分正常游戏的玩家最终都会遭遇落马结局

### 2. 好结局条件过于苛刻

原始代码：
```javascript
else if (integrityScore >= 75 && totalScore >= 65 && rank >= 3) {
    // 光荣退休结局
}
```

**问题**：
- 需要廉洁度 ≥75（很难维持）
- 平均属性 ≥65（需要所有属性都高）
- 职级 ≥3（需要多次晋升）

这导致几乎无法达成好结局。

### 3. LLM选项效果偏向负面

原始提示词仅强调低廉洁度时的风险事件，未要求提供正面选项：
```javascript
if (attrs.integrity < 40) attrHints.push('廉洁度很低，应生成利益诱惑升级或被调查的风险事件');
```

## 修复方案

### 1. 调整风险系数

```javascript
const diffFactor = difficulty === 'easy' ? 0.6 : difficulty === 'hard' ? 1.2 : 0.9;
if (risk >= 85) {
    // 只有极高风险才落马
}
```

**效果**：
- 简单模式：廉洁度<17才会落马
- 普通模式：廉洁度<28才会落马
- 困难模式：廉洁度<42才会落马

### 2. 放宽好结局条件

```javascript
// 计算综合表现评分：60%来自属性平均分，40%来自职级进度
const performanceScore = totalScore * 0.6 + (rank / maxSteps) * 100 * 0.4;

else if (integrityScore >= 70 && performanceScore >= 60 && rank >= 2) {
    // 光荣退休（放宽条件）
}
```

**效果**：
- 廉洁度要求从75降到70
- 增加综合表现评分机制
- 职级要求从3降到2

### 3. 平衡结局分布

```javascript
else if (integrityScore >= 50 && performanceScore >= 45) {
    // 平稳落幕（进一步放宽）
}
else if (integrityScore >= 35) {
    // 调任闲职（新增中等结局区间）
}
else {
    // 受到处分（只有廉洁度<35）
}
```

### 4. LLM提示词优化

```javascript
// 修复：确保选项效果平衡
attrHints.push('重要：四个选项的效果必须平衡分布，至少有2个选项应该包含正面的属性增益，廉洁度变化必须正负兼有');
```

## 修复效果对比

### 测试结果（30个场景 × 3个难度）

| 结局类型 | 原始分布 | 修复后分布 |
|---------|----------|-----------|
| 落马 (BAD) | 43.3% | 16.7% |
| 处分 (MID2) | 46.7% | 43.3% |
| 闲职 (MID) | 0% | 30.0% |
| 平稳 (GOOD) | 10.0% | 10.0% |
| 光荣 (GREAT) | 0% | 0% |

**关键改进**：
- 坏结局减少 26.7%
- 新增中等结局区间（30%）
- 结局分布更加平衡和合理

## 用户体验改进

1. **更合理的结局分布**：大部分玩家将获得中等或以上的结局
2. **难度更贴近现实**：只有在极端情况下才会落马
3. **选项更平衡**：LLM生成的选项包含正面和负面效果
4. **可玩性提升**：玩家的选择更有意义，不会总是走向坏结局

后续如需调整难度平衡，可修改以下参数：

1. `diffFactor`: 各难度的风险系数
2. `risk >= 85`: 落马阈值
3. `integrityScore >= 70`: 光荣退休廉洁度要求
4. `performanceScore >= 60`: 光荣退休表现要求
